# Jami3ty (جامعاتي) - Complete Native Android Project

Projet native Android complet prêt pour la génération automatique de l'APK via GitHub Actions.

## Structure du projet :
- Architecture Kotlin propre (Data, Security, UI).
- Authentification Biométrique (Empreinte digitale / Face ID).
- Stockage Sécurisé (`EncryptedSharedPreferences`).
- Intégration Firebase Firestore.
- Workflow CI/CD GitHub Actions pour générer le fichier APK `.apk`.
